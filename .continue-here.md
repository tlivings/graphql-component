### Bugs to Fix (7) -- all in src/index.ts

1. **Transform loop breaks on falsy returns** (line 423)
   - `if (!result) { break; }` treats `null`, `0`, `false` as stop signals
   - Fix: change to `if (result === undefined) { break; }`

2. **`federation` setter doesn't invalidate schema** (line 381-383)
   - Setting federation after schema is cached has no effect
   - Fix: call `this.invalidateSchema()` in the setter

3. **Use-after-dispose on cached context function** (line 281)
   - Stored reference to `component.context` works post-dispose with confusing errors
   - Fix: add `this._assertNotDisposed()` at the top of `contextFn` (line 216)

4. **`stableStringify` throws on circular references** (line 538)
   - `JSON.stringify(args[k])` crashes on circular objects
   - Fix: wrap in try/catch, fall back to placeholder string

5. **Data source empty string name falls back to constructor name** (line 509)
   - `dataSource.name || dataSource.constructor.name` -- empty string is falsy
   - Fix: `dataSource.name != null ? dataSource.name : dataSource.constructor.name`

6. **Namespace can shadow `dataSources` key** (line 254)
   - `contextConfig.namespace === 'dataSources'` replaces the DataSourceMap
   - Fix: add validation in `validateConfig` that namespace !== 'dataSources'

7. **Import injector crashes on custom IGraphQLComponent** (line 208-209)
   - `component.dataSources` and `component.dataSourceOverrides` are optional in interface
   - Fix: default to `[]` in `createDataSourceContextInjector` call
